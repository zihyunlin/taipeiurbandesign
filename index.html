🏙 臺北市都市設計審議（都審）是什麼？

申請建照前，建築計畫須通過都市設計審議，取得核定函後方可申請建造執照

都審核心目的為什麼要做都審？
🌳

公共開放空間品質

開放空間系統配置、綠化保水、步行環境串連

🏗

建築量體與風貌

高度、造型、色彩、立面語彙、景觀計畫

🚗

交通動線整合

停車空間配置、車道出入口位置、人行安全

法源依據都審審什麼？（都計定通§9第2項）
  • 🟢 公共開放空間系統配置及其綠化、保水事項
  • 🟢 人行空間、步道或自行車道系統動線配置
  • 🟢 交通運輸系統、停車空間及出入動線配置
  • 🟢 建築基地細分規模及地下室開挖之限制
  • 🟡 建築量體配置、高度、造型、色彩、風格
  • 🟡 綠建材及水資源回收再利用之事項
  • 🟡 環境保護設施及資源再利用設施配置
  • 🟡 景觀計畫
  • 🟡 防災、救災空間及設施配置 ／ 管理維護計畫
法源：臺北市土地使用分區管制自治條例§95 授權訂定「審議規則」、「收費辦法」及各相關都市設計準則
程序選擇四種審議層級一眼看懂
層級程序名稱非公有土地（樓地板面積）費用審議單位
最高一般審議≥ 10,000㎡ 且基地 ≥ 5,000㎡$85,000幹事會初審 → 委員會
專案審議≥ 10,000㎡（其他類型）$80,000幹事會初審 → 專案委員會
簡化審議3,000㎡ ≤ 樓地板 ＜ 10,000㎡$45,000簡化委員會
最低幹事會審議＜ 3,000㎡$35,000幹事會逕行審議

*公有土地、學校、社宅等公有案件，依樓地板面積另有不同對應程序，詳見「送審資格」頁。山坡地（基地≥2,000㎡）→ 專案；大稻埕地區 → 專案。

📋 送審資格（哪些案件要送都審？）

符合下列任一條件，即須辦理都市設計審議後方可申請建造執照

兩大送審來源：① 位於都市計畫書載明之都審地區（可至都市開發審議地圖查詢），或 ② 符合審議規則§3 所列大規模建築物條件（全市適用）
審議規則§3大規模建築物定義（13款，符合任一即須送審）
款適用條件對應程序
一基地面積達 6,000㎡，且總樓地板面積達 30,000㎡一般審議
二依建築法§98 許可之特種建築物（捷運工程、軍事除外）
三基地面積達 10,000㎡ 之公共設施用地廣場或公園整體規劃案一般審議
四基地面積達 6,000㎡ 之立體停車場（建築物附屬除外）
五基地面積達 6,000㎡ 適用都市計畫公共設施用地多目標使用辦法
六人行陸橋或跨越淡水河、基隆河、新店溪或景美溪之橋梁一般審議
七公有土地適用促參法、捷運土地開發辦法或設定地上權，且總樓地板面積達 30,000㎡
八樓地板面積達 15,000㎡ 之公有建築物、各級學校（含幼兒園）或政府新建社會住宅一般審議
九第八款建築物基地新增樓地板面積達 5,000㎡
十高架捷運車站或地面層捷運出入口一般審議
十一適用臺北市都市計畫劃定山坡地開發建築管制規定（特定情形免送）專案審議
十二容積移轉移入量達接受基地原基準容積 30%
十三其他經本府認定有重大妨礙公共安全、景觀或文化資產保存之虞者

📄 紙本掛件應備文件
  • 線上二維申請書（有效期內，正章用印）
  • 都審報告書（正章用印）
  • 委託書、切結書、資訊同意書（正章用印）
  • 建築計畫資料表
  • 汽車位 >150輛 → 附交評報告書
  • 3D模型（新案/變更設計）：skp≤2018或ifc格式，正北方向，單位公尺
📋 報告書必備圖說
  • 敷地計畫 ／ 設計說明
  • 建築物圖說（各層平面、立面、剖面）
  • 景觀植栽計畫
  • 建築物造型及色彩計畫
  • 車行與交通動線規劃
  • 消防救災空間及動線規劃
  • 受保護樹木影響評估（如適用）
  • 核定階段：R6-1~R6-4 公開圖說

✏️ 變更設計

核定後需修改設計時，應判斷是否需重新辦理都審程序

判斷流程是否需重新辦理都審？
已核定之都審案 ── 需要修改設計
符合以下任一免辦理條件？
且不違反土管自治條例、都計規定及原決議
✅ 是（符合免辦條件）
免申請都審變更設計
直接向建管處辦理
❌ 否（不符合免辦）
需重新申請都審
費用依對應程序收費（$10,000~$85,000）
審議規則§8五款免辦理變更設計條件
款免辦理情形範例說明
一 調整項目符合「免辦理變更設計項目一覽表」（110.05.11），或不影響原核定方案 詳見都審服務平台下載一覽表
二 用途變更不影響原核定方案及停車位之配置 樓層用途局部調整，停車位數量不變
三 附屬設施之變更未影響景觀 機電設備位置小幅調整，外觀未改變
四 綠化設施係同一種別植栽種類變更（樹種或草種） 將某品種喬木換為另一品種喬木
五 經指定留設之開放空間，未變更可視性及可及性功能 開放空間鋪面材料變更，位置不變
另注意：結構形式調整、基礎型式、工程經費調整等不涉及都審審查範疇之變更，免予送審（直接向建管處辦理）。
⏰ 時程：變更設計案之作業程序，準用審議規則第7條之送審時限規定。費用：若委員會認定與原核定案無變更或幅度不大，僅收 $10,000；否則依對應審議程序全額收費。

⚠️ 必遵守規範（審議注意事項）

這些是申設單位應自行確認符合的規劃設計標準，與「審議參考範例」（原則性）不同，必須遵守

⚠ 重要說明：審議注意事項為強制規範，申設單位應於送件前自行逐條檢核，委員會審議時將直接要求符合，無法以「基地條件限制」為由豁免。
一都市設計規劃及分析說明
  • 以都市尺度、街廓尺度及人行尺度進行周邊交通、量體、開放空間等面向之分析
  • 充分考量基地周邊既有紋理（現有巷弄、周邊建物立面語彙、顏色、量體高度），並納入設計準則規範
  • 地面層開放空間確保區域使用用途、騎樓空間、人車動線及外部空間之延續性，配合加強景觀植栽整體規劃
二公共空間及綠化
  • 地面層設備及通風設施應避開主要開放空間及人行動線，與建築物主體整併
  • 開放空間人行鋪面材質均應符合防滑標準（C.S.R. ≥ 0.75）
  • 現況樹型良好之喬木或樹群，原地保留或於原基地內移植
  • 非開挖區以栽植喬木取代人工設施物
  • 開放空間花臺及座椅高度不超過 45 公分
  • 圍牆高度不高於 2 公尺；臨道路側基座不超過45公分、透空率 ≥ 70%
  • 開放空間應避免使用投樹燈
  • 設置階梯：級高 ≤ 15公分、級深 ≥ 28公分
三建築設計規劃
  • 服務性陽台及空調設備設於臨道路側，應有遮蔽美化設施
  • NEW 113.07 立面材料建議避免使用燒面石材（燒面大理石強度僅為一般石材 1/2）
  • 商業區（含特定商業區）及工業區，不設置圍牆或高度 45公分以上綠籬
  • 都市計畫不得作住宅區域：申請人切結不得作住宅使用，納入建照記載及地政登記注意事項
  • 廣告物：LED廣告物播放時影像亮度避免炫光；帷幕牆內側避免設置閃光型廣告物
四交通及停車空間
  • YouBike 優先設置於地面層開放空間；自身使用之自行車位留設 2公尺淨寬操作空間
  • 機車車道淨寬 ≥ 1.5公尺，坡道斜率 < 1/8 並鋪設防滑材料
  • NEW 各層機車停車位應集中設置（避免散佈各層造成汽機車交織）
  • 車道出入口地坪與相鄰人行空間順平，鋪面系統避免使用車道磚且延續人行道鋪面型式
  • 開發基地鄰接公車站者，應於退縮空間內預留候車亭位置
五古蹟及舊城區街道周邊
  • 面向古蹟側立面：量體輪廓簡潔；避免工作陽台及附掛式設備；避免閃爍式燈光
  • 鄰近古蹟量體分析：以人的視角繪製量體分析圖及古蹟周邊天際線影響模擬圖
  • 舊城區街道（萬華廣州街、貴陽街、大同哈密街、中正衡陽路、博愛路等）：設計呼應都市紋理
  • 國定古蹟總統府後方：高度不超過總統府山型天際線（應先經文化部確認）
六公共工程

校園開發案

  • 提出分期分區發展計畫（含既有建築面積、容積、車位、預計開發量、人車動線）
  • 新建建築地坪高程避免抬高，友善建物與都市外部空間界面
  • 家長接送區於基地內化處理，避免影響外部交通

醫院

  • 急診區外部空間含 4公尺緊急救護動線及4公尺淨寬以上作業空間

社會住宅 NEW 113.07

  • 優先試辦地面層預為規劃臨停上下車空間（考量高齡化趨勢）
七山坡地
  • 檢附臺北市山坡地保育利用資訊查詢系統查詢結果或大地處函文，確認是否屬山坡地
  • 位於山坡地者，檢附水土保持規劃書（以30頁內為原則），併入都審報告書附錄
  • 坵塊分析：以88年公告之實測地形圖及技師簽證現況測量圖進行，方格尺度及格位位置均應相同
  • 開發案清楚標示基地內、外高程及整地前後說明，於剖面圖說套繪現況地形
  • 山坡地擋土牆避免與建物外牆共構

🌿 臺北市新建建築物綠化實施規則

114年7月31日修正發布，自 115年1月1日起施行（全文17條）

🔗 法規原文：臺北市法規查詢系統 — 臺北市新建建築物綠化實施規則（FL080927）
沿革：中華民國114年7月31日府法綜字第1143034143號令修正發布全文17條；並自115年1月1日施行。
新增概念（115年版）綠容率（§3、§5）

定義

  • 等效綠覆面積：各植栽綠覆面積 × 降溫係數
  • 綠容率：等效綠覆面積總和 ÷ 建築基地面積

降溫係數

植栽種類降溫係數
高遮蔭喬木3.0
低遮蔭喬木2.0
灌木1.2
其他植栽種類1.0

計算公式

綠容率 =
[喬木面積(㎡)×喬木降溫係數
＋灌木面積(㎡)×1.2
＋其他植栽面積(㎡)×1.0]
÷ 建築基地面積(㎡)
§4、§5五類建築基地分類與規定（115年1月1日起）
類別適用條件綠覆率綠容率固碳當量基準（kg/㎡·年）
第一類 新開闢一公頃以上公園用地之建築基地 ≥ 90%≥ 2.00.99
第二類 完整街廓；公有建築物及各級學校；基地≥1,000㎡且實設容積較法定容積增加 ≥ 80%≥ 1.90.83
第三類 基地≥1,000㎡，或500㎡~1,000㎡且容積增加；第一類以外之公園用地、既有公有建築物或學校 ≥ 70%≥ 1.80.83
第四類 基地500㎡~1,000㎡；住宅區≥300㎡，或非住宅區300~500㎡且容積增加 ≥ 60%≥ 1.60.66
第五類 前四類以外之建築基地 ≥ 50%≥ 1.40.66
注意：基地跨越二個以上使用分區，以所占面積較大之使用分區認定類別。同時符合多類時，以序號在前者認定。
§7法定空地植栽重點規定（115年版）

喬木覆土深度

  • 喬木、棕櫚類：150公分以上（120~150cm：綠覆面積以80%計；100~120cm：以60%計）
  • 灌木類：60公分以上
  • 藤蔓、草花、地被、草皮：30公分以上

退縮帶狀開放空間（臨道路側≥3.64m）

  • 喬木綠覆面積應占開放空間面積 ≥ 80%
  • 臨道路側1.5m範圍內種植行道樹：覆土深度2公尺，株距4~6公尺，分枝高度距地面2.5公尺以上
  • 單獨植栽穴面積：大喬木≥4㎡、中喬木≥2.5㎡、小喬木≥1.5㎡
§9屋頂平台綠化
  • 屋頂平台綠覆面積應達屋頂平台面積之 50%（法令另有規定者除外）
  • 灌木類綠覆面積應達屋頂平台綠覆面積 30% 以上
  • 因綠化增加之必要設備層或植栽覆土，高度在 80公分以下，不計入建築物高度
  • 緊鄰女兒牆設置綠化設施者，覆土完成面女兒牆高度不足1.5m部分應設置透空欄杆
§12透水鋪面規定
  • 各類建築基地內車道、人行步道或廣場等鋪面，應設置 ≥ 50% 面積之透水性材料
  • 並與臨接道路之人行道順平
  • 透水鋪面下方覆土深度至少應有 30公分之砂石級配層
建造執照申請時須附：植栽配置平面圖（比例≥1/100）、植栽剖面詳圖（比例≥1/50）、綠容率檢討表、綠覆率檢討表、固碳當量檢討表
